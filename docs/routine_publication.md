# Procedimento consolidado

Use [Publicação do WahoJobs](publication.md) e `scripts/publication.py` para todas
as classes, inclusive coordenadas. O protocolo comum substitui o fluxo v1 de
rotina. Seus recibos e ensaios permanecem como evidência histórica.

API/backend, dados e infraestrutura têm caminhos executáveis no mesmo fluxo.
Não herde mínimos de janela, censos, sign-ins ou esperas horárias de incidentes.
O ponto de publicação v1 recusa novas mutações após a transição ativa.
