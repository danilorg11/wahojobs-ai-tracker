# wahojobs-ai-tracker

The ordinary local product application remains authentication-dormant. The
reviewed development, test, and private-beta browser activation for durable
Google login is available only through its explicit local HTTPS launcher.

See [Durable Google Login Browser Activation](docs/durable_google_login_browser.md)
for the exact configuration, route, cookie, delivery-boundary, demo, and
deployment limitations.

The production-grade, guest-only origin and isolated Vercel preview proof for
the public jobs catalog are documented in
[Production-origin + preview-only `/jobs` proof](docs/production_origin_preview.md).
They do not activate any route on `www.wahojobs.com`.
